# 에버랜드 3D 가상 공간 — 할 일 목록

> 프로젝트 경로: `amusemen_park/` (`server/`, `client/`, `shared/`)
> 통신 문서: `doc/놀이동산_온라인.xlsx` / 실행 방법: `doc/놀이동산_실행방법.md`

## 기술 결정

| 항목 | 결정 |
|------|------|
| 언어 / 런타임 | TypeScript, Node.js v26 |
| 서버 | Colyseus 0.18 (`@colyseus/core`·`ws-transport`·`schema`) |
| 클라이언트 | Three.js + Vite, `@colyseus/sdk` |
| 공용 코드 | `shared/` — 상수·판정 규칙, `@shared` 별칭 |
| 3D 모델 | 코드로 만든 도형 (오리 모델은 `duckModel.ts`만 바꾸면 glTF 교체 가능) |
| 그림체 | 파스텔 툰 셰이딩, 둥근 도형 |
| 대상 | PC(키보드·마우스) + 모바일(조이스틱·터치) |
| 글꼴 | 원스토어 모바일 POP체 (한글·영문만, 그 외 문자는 시스템 글꼴) |
| 언어 | UI 한국어, 채팅은 다국어 예정 |

## 3단계. 서버 — `ParkRoom`

- [x] 방 정원 50, 초과 시 새 방(번호 부여·재사용), 상태 동기화 20Hz
- [x] 입장: 별명 검증·중복 거부(같은 방 기준), 플레이어마다 다른 색 배정
- [x] 이동 검증(최대 속도 8 × 허용 1.5·맵 범위), 거부 시 `move_correction`
- [x] 탑승·하차·NPC 대화 요청 처리 (기구 근처 판정 `isNearRide`)
- [x] 퇴장 처리, 비정상 끊김 20초 재접속 유예
- [x] 방 시각 동기화(`time_sync`) — 모든 화면의 놀이기구 움직임 일치

## 4단계. 3D 월드

- [x] 씬·조명·하늘·구름, 구역 바닥·길·표지판·정문, 나무·꽃·가로등·울타리
- [x] 놀이기구 9종 모델·운행 애니메이션·좌석 위치(서버 좌석 수와 일치)
- [x] 기구 물리: 코스터는 에너지 보존·마찰·체인 리프트·브레이크·정차 시간표와 커브 뱅크·체감 G, 롤링 엑스 트레인 클로소이드 루프, 렛츠 트위스트·콜럼버스 진자 펌핑
- [x] T익스프레스: 평면 경로+높이 단면 설계, 직선 체인 리프트·77° 낙하·에어타임 언덕, 목재 A자 구조물
- [x] 썬더폴스: 정상 180° 턴테이블 → 백워드 드롭 → 리버싱 룸 → 큰 낙하 → 착수 물보라
- [x] 콜럼버스 대탐험: 뾰족한 선체의 스윙 보트(최대 75°)
- [ ] 그리기 호출 줄이기(고정 도형 합치기·인스턴싱)

## 5단계. 캐릭터

- [x] 새끼 오리 모델(메시 6개)·대기/걷기/앉기 애니메이션·이름표, 스릴 기구에서 날개를 들고 파닥임(에어타임에 몸이 뜸)
- [x] 3인칭 카메라(드래그 회전·확대), 키보드·조이스틱 이동

## 7단계. 놀이기구 탑승

- [x] 기구 근처에서 머리 위 말풍선 '타기'(빈자리 수, E 키), 탑승 중 오른쪽 아래 '내리기'
- [x] 좌석에 앉아 기구와 함께 이동, 우측 상단 탑승 시점 화면, 만석 안내
- [x] 범퍼카 직접 운전·서버 물리 충돌, 충돌 효과·화면 흔들림

- [x] 탑승 중 덜컹거림을 휴대폰 진동으로 전달 (안드로이드 브라우저, 에어타임엔 진동 멈춤)
- [x] 기구별 효과음(체인·굉음·떨림·브레이크·물폭탄·범퍼 충돌·비명)과 놀이공원 배경음(군중·먼 기구·회전목마 음악), 소리 켜기/끄기 버튼(설정 기억)
