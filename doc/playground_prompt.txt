#에버랜드를 3D 가상 공간 만들기
-첫 페이지는 간단한 소개 페이지로 구성 되어 있고, 별명 입력칸과 입장 버튼이 있다.
-전체 지도는 제공한 에버랜드 이미지를 참고하여 맵을 구성한다.
-놀이 기구의 종류는 아래와 같이 각 영역별로 인기 있는 놀이기구만 배치를 한다.
	아메리칸 어드벤처 : 롤링 엑스 트레인, 렛츠 트위스트
	매직랜드 : 썬더폴스, 범퍼카
	유러피안 어드벤처 : T익스프레스
	주토피아 : 사파리월드, 로스트밸리, 판다월드
-실제 게임 기구가 배치 되고, 내 캐릭터가 기구 앞에 가면 '타기' 를 할 수 있는 버튼이 표시
-각 기구에는 기구를 타고 있는 NPC오리를 배치 해 줘. 이름도 npc_번호 같이 구성 해줘.
-npc 에게 말을 걸 겨우 몇개의 대화 리스트가 나오고, npc도 그에 맞는 대답을 하면 됨
-타기를 하면 놀이 기구의 빈자리에 실제 앉는 모습이 나온다. 
-온라인으로 타인의 캐릭터의 움직임과 머리위 이름을 볼 수 있다.
-기구를 타면 우측 상단에 기구를 탄 상태에서 보여지는 모습을 실제 뷰로 보여 준다.
-캐릭터는 새끼 오리를 배치한다. 모든 사용자의 오리색은 다르게 정해 준다.
-typescript, node, 서버 프레임워크 Colyseus 를 사용 한다.
-pc 버전, 모바일 버전 모두 가능 하게 한다.
-코딩은 server 와 client 를 분리하여 amusemen_park 폴더안에서 프로젝트를 관리 할 수 있도록 한다.
-추후 캐릭터를 고도화 한다.
-서버와 클라이언트 간의 통신 내용을 d:\work\study\playground_vibe\doc\놀이동산_온라인.xlsx 에 빠짐없이 기록한다.
현재 빨간색 부분은 예시로써 참고하여 문서를 작성 한다.
-우선 할일에 대해 목록을 작성 한다.
-여러 파일에 걸친 큰 작업(리팩토링, 기능 추가, 코드베이스 분석)은 Ruflo(MCP)의 에이전트/스웜 도구를 사용합니다.
-단순 수정이나 질문은 Ruflo 없이 직접 처리합니다.
