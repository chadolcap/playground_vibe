# 놀이동산 3D — 실행 방법

> 필요 환경: Node.js v22 이상 (개발 환경 v26), npm

## 1. 의존성 설치 (최초 1회)

서버와 클라이언트는 각각 따로 설치한다.

```bash
cd amusemen_park/server
npm install

cd ../client
npm install
```

## 2. 환경 변수 설정 (선택)

`.env` 파일이 없으면 아래 기본값으로 동작한다.

| 위치 | 변수 | 기본값 | 설명 |
|------|------|--------|------|
| `amusemen_park/server/.env` | `PORT` | `2567` | 서버 포트 |
| `amusemen_park/client/.env` | `VITE_SERVER_URL` | 페이지를 연 주소의 `2567` 포트 (예: `http://192.168.x.x:2567`) | 클라이언트가 접속할 서버 주소 (서버를 다른 컴퓨터에 둘 때만 지정) |

- https 페이지나 배포 빌드에서는 게임 서버 주소가 페이지와 다르므로 `VITE_SERVER_URL`을 반드시 지정한다 (없으면 콘솔 경고 후 페이지 호스트의 2567 포트로 접속).
- `.env` 파일은 git에 커밋하지 않는다.
- 클라이언트의 `.env`를 수정한 뒤에는 클라이언트를 다시 실행해야 반영된다.

## 3. 서버 실행

```bash
cd amusemen_park/server
npm run dev
```

- 아래 메시지가 나오면 정상이다.
  ```
  [server] 포트 2567 에서 대기 중 (방 이름: "park")
  ```
- `server/src`, `shared/` 파일을 수정하면 서버가 자동으로 재시작된다. 이때 접속 중인 플레이어의 연결이 끊기므로 브라우저를 새로고침해 다시 입장한다.

## 4. 클라이언트 실행 (새 터미널)

서버를 띄운 터미널은 그대로 두고, 새 터미널을 열어 실행한다.

```bash
cd amusemen_park/client
npm run dev
```

- 파일을 수정하면 브라우저가 자동으로 갱신된다.

## 5. 브라우저 접속

| 기기 | 주소 |
|------|------|
| 서버를 띄운 PC | http://localhost:5173 |
| 같은 네트워크의 다른 PC·모바일 | Vite 실행 화면의 `Network:` 줄에 나오는 주소 (예: `http://192.168.x.x:5173`) |

별명을 넣고 **입장하기**를 누르면 정문 안쪽에 내 오리가 나타난다. 좌측 상단에 방 번호와 미니맵(빨간 화살표 = 나, 파란 점 = 다른 오리)이 보인다.

| 동작 | PC | 모바일 |
|------|----|--------|
| 이동 | `W` `A` `S` `D` / 방향키 | 조이스틱 |
| 자동 걷기 | 땅 더블클릭, 미니맵 클릭 | 땅 더블탭, 미니맵 탭 |
| 시점 회전·확대 | 마우스 드래그, 휠 | 화면 드래그, 두 손가락 |
| 미니맵 확대·축소 | 미니맵 `+`/`−` 버튼, 미니맵 위에서 휠 | `+`/`−` 버튼, 미니맵 위에서 두 손가락 |
| 효과음 켜기/끄기 | 오른쪽 위 🔊/🔇 버튼 (설정은 다음 접속에도 유지) | 같음 |
| 놀이기구 타기 | 기구 근처 머리 위 말풍선 `타기` 또는 `E` | 말풍선 `타기` |
| 내리기 | 오른쪽 아래 `내리기` 또는 `E` | `내리기` |
| 범퍼카 운전 | `W`·`S` 가속·후진, `A`·`D` 핸들 | 조이스틱 |
| NPC 대화 | 말풍선 `npc_N에게 말 걸기` | 같음 |

- 같은 방의 다른 플레이어가 실시간으로 보인다. 방은 50명이 차면 새 방이 생기므로 다른 방 사람은 보이지 않는다.
- 같은 방에 같은 별명으로는 입장할 수 없다.
- 놀이기구 9종: 롤링 엑스 트레인·렛츠 트위스트·썬더폴스·범퍼카·T익스프레스·사파리월드·로스트밸리·판다월드·콜럼버스 대탐험 (콜럼버스는 가장 높이 올라가는 배 양 끝 좌석부터 앉음)
- 스릴 기구를 타면 탑승 시점 화면에 속도(km/h)·G가 나오고, 몸이 뜨는 순간에는 `🪶 에어타임!`, 3G 이상이면 `💥` 표시가 붙는다.
- 휴대폰으로 스릴 기구를 타면 덜컹거림이 진동으로 전해진다 (안드로이드 크롬·삼성 인터넷, iOS 사파리는 진동하지 않음).
- 브라우저 정책 때문에 소리는 화면을 한 번 누르거나 키를 누른 뒤부터 난다. 기구 소리는 타고 있으면 크게, 근처에 있으면 거리에 따라 작게 들린다.

## 6. 다른 PC·모바일에서 접속

클라이언트는 페이지를 연 주소와 같은 컴퓨터의 `2567` 포트로 게임 서버에 접속하므로 따로 설정할 것이 없다.

1. 서버 PC의 IP 확인: `ipconfig` → `IPv4 주소`
2. 다른 기기 브라우저에서 `http://<서버 PC IP>:5173` 접속
3. 페이지가 열리지 않거나 입장이 안 되면 확인한다.
   - 두 기기가 같은 네트워크(공유기)에 연결되어 있는지
   - 서버 PC의 Windows 방화벽에서 Node.js 접속이 허용되어 있는지 (현재 네트워크 종류 `공용`/`개인`에 맞게)
   - `amusemen_park/client/.env`에 `VITE_SERVER_URL=http://localhost:2567`처럼 `localhost`가 적혀 있지 않은지 (다른 기기에서는 자기 자신을 가리킴)

## 7. 빌드 결과물로 실행 (선택)

배포 형태로 확인할 때 사용한다.

```bash
# 서버
cd amusemen_park/server
npm run build    # 타입 검사 후 dist/index.js 생성
npm start

# 클라이언트 (새 터미널)
cd amusemen_park/client
npm run build    # 타입 검사 후 dist/ 생성
npm run preview  # http://localhost:4173
```

## 8. 통신 문서 점검

서버·클라이언트 통신(메시지 type·payload 필드, 오류 코드·표시 문구, 상태 스키마 필드, 기구 좌석·NPC, 통신 상수)을 바꾼 뒤에는 통신 문서와 일치하는지 확인한다.

```bash
PYTHONIOENCODING=utf-8 python amusemen_park/scripts/check_protocol_doc.py
```

- `통신 문서와 코드가 일치합니다.` 가 나오면 정상
- 불일치 항목이 나오면 `doc/놀이동산_온라인.xlsx` 를 갱신한다. (Python `openpyxl` 필요)

## 9. 문제 해결

| 증상 | 원인 / 해결 |
|------|-------------|
| `EADDRINUSE` 오류 | 포트가 이미 사용 중이다. 기존 서버를 종료하거나 `.env`의 `PORT`를 바꾼다 |
| `PORT 환경 변수가 올바르지 않습니다` | `PORT`에는 1~65535 사이의 숫자만 넣는다 |
| `VITE_SERVER_URL 은 http(s) 주소여야 합니다` | `ws://`가 아니라 `http://` 형식으로 적는다 |
| 모바일에서 페이지가 열리지 않음 | PC와 같은 와이파이인지, 방화벽이 허용되어 있는지 확인한다 |
| 입장 시 `서버에 연결할 수 없어요` | 서버가 실행 중인지, `VITE_SERVER_URL` 주소가 맞는지 확인한다 |
| 소리가 안 남 | 화면을 한 번 누른다 · 🔇 상태인지, 휴대폰 무음 모드인지 확인한다 · 구형 브라우저(iOS 14.0 이하 등)는 소리 없이 진행된다 |
| 진동이 안 됨 | iOS 사파리는 진동을 지원하지 않는다 (안드로이드 크롬·삼성 인터넷만) |
| 점검 스크립트에서 한글 인코딩 오류 | `PYTHONIOENCODING=utf-8` 을 붙여 실행한다 |
